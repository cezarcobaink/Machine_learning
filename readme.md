# Machine Learning — competições do Kaggle

|---|---|---|---|
| [House Prices](Houses) | Regressão | XGBoost | RMSLE de 0,142 |

| [Spaceship Titanic](Spaceship%20Titanic) | Classificação binária | Random Forest | Acurácia de 78% |
